# CSV

## What is CSV?

Think of a spreadsheet. Rows of data, columns with headings, every row representing one record — one student, one order, one sensor reading. A CSV file stores exactly that kind of data, but as plain text.

**CSV** stands for Comma-Separated Values. Each line is one row. Within a line, values are separated by commas. The first line is usually a header row giving each column a name.

A CSV file looks like this:

```text
name,age,grade
Alex,21,A
Maria,20,B
James,22,A
```

That is three students. Each has a name, an age, and a grade. Open this in Excel or Google Sheets and it becomes a familiar table. Keep it as a `.csv` file and your Python program can read every row with a few lines of code.

Python's built-in `csv` module handles CSV files. You could parse them manually — split each line on commas — but the `csv` module handles edge cases for you, such as values that contain commas or quote marks themselves. No installation needed.

## Reading CSV

### csv.reader

`csv.reader` wraps a file object and gives you one row at a time, as a list of strings.

Assume `students.csv` contains:

```text
name,age,grade
Alex,21,A
Maria,20,B
James,22,A
```

```python
import csv

with open("students.csv", "r") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
```

**Output**

```text
['name', 'age', 'grade']
['Alex', '21', 'A']
['Maria', '20', 'B']
['James', '22', 'A']
```

Every value comes back as a string — including the age. Convert with `int()` or `float()` if you need to do arithmetic.

The first row is the header. To skip it so you only process data rows, call `next()` once before the loop:

```python
import csv

with open("students.csv", "r") as file:
    reader = csv.reader(file)
    next(reader)                      # skip the header row
    for row in reader:
        name, age, grade = row
        print(f"{name} — Age: {age}, Grade: {grade}")
```

**Output**

```text
Alex — Age: 21, Grade: A
Maria — Age: 20, Grade: B
James — Age: 22, Grade: A
```

### csv.DictReader

`csv.DictReader` uses the header row as keys, so each row comes back as a dictionary instead of a list. This makes the code easier to read — `row["name"]` is clearer than `row[0]`, and the order of columns in the file stops mattering.

```python
import csv

with open("students.csv", "r") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row["name"], "scored grade", row["grade"])
```

**Output**

```text
Alex scored grade A
Maria scored grade B
James scored grade C
```

`DictReader` skips the header automatically — it uses it to build the keys. Each `row` is an `OrderedDict` but behaves exactly like a regular dictionary for reading values.

### Filtering Rows While Reading

Because each row is just a list or dictionary, you can apply conditions with `if` as you go:

```python
import csv

with open("students.csv", "r") as file:
    reader = csv.DictReader(file)
    for row in reader:
        if row["grade"] == "A":
            print(row["name"])
```

**Output**

```text
Alex
James
```

For numeric comparisons, convert first:

```python
if int(row["age"]) >= 21:
    print(row["name"])
```

## Writing CSV

### csv.writer

`csv.writer` is the writing counterpart to `csv.reader`. Call `writerow()` once per row, or `writerows()` to write a list of rows at once.

```python
import csv

students = [
    ["name", "age", "grade"],
    ["Alex",  21, "A"],
    ["Maria", 20, "B"],
    ["James", 22, "A"]
]

with open("students.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerows(students)

print("Saved")
```

**Output**

```text
Saved
```

`newline=""` prevents Python from adding an extra blank line between rows on Windows. It does nothing on Mac or Linux, so it is safe to always include it.

The first list in `students` is the header row — `csv.writer` does not know or care which row is a header; it writes whatever you give it.

### Appending Rows

To add rows without erasing existing ones, open with mode `a` instead of `w`:

```python
import csv

new_student = ["Sam", 20, "B"]

with open("students.csv", "a", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(new_student)

print("Row added")
```

**Output**

```text
Row added
```

### csv.DictWriter

`csv.DictWriter` takes a list of dictionaries and writes them as rows, using the keys as column headers. The column names must be declared up front in `fieldnames`.

```python
import csv

students = [
    {"name": "Alex",  "age": 21, "grade": "A"},
    {"name": "Maria", "age": 20, "grade": "B"},
    {"name": "James", "age": 22, "grade": "A"}
]

with open("students.csv", "w", newline="") as file:
    fields = ["name", "age", "grade"]
    writer = csv.DictWriter(file, fieldnames=fields)
    writer.writeheader()
    writer.writerows(students)

print("Saved")
```

**Output**

```text
Saved
```

`writeheader()` writes the column names as the first row. Without it, the file has data rows but no headings, which is valid CSV but difficult to work with later.

## Quick Reference

| | `csv.reader` / `csv.writer` | `csv.DictReader` / `csv.DictWriter` |
|---|---|---|
| Each row is | A list | A dictionary |
| Header row | Comes back as the first row — skip with `next()` | Used automatically as keys |
| Access a value | `row[0]` | `row["name"]` |
| When to use | When column order is fixed and known | When column names make the code clearer |

## Common Mistakes

- Forgetting `import csv` — the module is built in but still needs importing.
- Omitting `newline=""` when writing on Windows — extra blank lines appear between every data row.
- Forgetting that every value from `csv.reader` is a string — comparing `row[1] > 70` silently compares strings, not numbers. Convert first: `int(row[1]) > 70`.
- Using `w` mode when you meant `a` — `w` silently erases the existing file before writing. Use `a` to add without erasing.
- Forgetting `writeheader()` with `DictWriter` — the file has no column names, making it hard to read back with `DictReader`.
- Passing a list to `DictWriter` — `DictWriter` expects dictionaries; use `csv.writer` for lists.
