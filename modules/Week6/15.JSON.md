# JSON

## What is JSON?

Imagine you want to save a student's profile — not just one value, but several things together: their name, their age, their enrolled courses. A plain text file can store words, but it has no way to express structure. It cannot say "these three things belong together as one student."

**JSON** (JavaScript Object Notation) solves this. It is a format for storing structured data — data that has named fields and values, just like a Python dictionary. It was invented for the web, but it is now the most widely used format for sharing data between programs, saving configuration, and receiving responses from APIs.

A JSON file looks like this:

```json
{
    "name": "Alex",
    "age": 21,
    "courses": ["Python", "AI", "Databases"],
    "is_active": true
}
```

If that looks familiar, it is because JSON is almost identical to a Python dictionary. The main differences are small but important:

| Python | JSON |
|---|---|
| `True` / `False` | `true` / `false` |
| `None` | `null` |
| Keys can be any hashable type | Keys must always be strings, in double quotes |

**Python's built-in `json` module reads JSON into Python dictionaries and writes Python dictionaries back out as JSON. No installation needed — it comes with Python.**

## Parsing JSON — Reading

### json.load()

`json.load()` reads a JSON file and hands back a Python dictionary. The word **parse** means converting text in a known format into a data structure your program can use.

Assume `student.json` contains:

```json
{
    "name": "Alex",
    "age": 21,
    "courses": ["Python", "AI", "Databases"],
    "is_active": true
}
```

```python
import json

with open("student.json", "r") as file:
    student = json.load(file)

print(student["name"])
print(student["age"])
print(student["courses"])
print(student["is_active"])
```

**Output**

```text
Alex
21
['Python', 'AI', 'Databases']
True
```

`student` is now an ordinary Python dictionary. The JSON `true` has become Python `True`, the number `21` is an `int`, and the array has become a list. You can read values from it, loop over it, pass it to a function — anything you would do with a dictionary you created yourself.

### json.loads()

Sometimes JSON arrives as a string rather than a file — this is exactly what happens when your program receives a response from an API over the internet. `json.loads()` parses a JSON string into a dictionary. The `s` at the end stands for string.

```python
import json

json_string = '{"name": "Alex", "age": 21, "is_active": true}'
student = json.loads(json_string)

print(student["name"])
print(type(student["age"]))
```

**Output**

```text
Alex
<class 'int'>
```

`json.loads()` is one of the most-used functions in real AI projects, because every time you call an external API it sends back JSON text. You parse it immediately to work with it as a dictionary.

## Constructing JSON — Writing

### json.dump()

`json.dump()` takes a Python dictionary and writes it into a file as JSON.

```python
import json

student = {
    "name": "Alex",
    "age": 21,
    "courses": ["Python", "AI", "Databases"],
    "is_active": True
}

with open("student.json", "w") as file:
    json.dump(student, file, indent=4)

print("Saved")
```

**Output**

```text
Saved
```

`indent=4` makes the file human-readable — without it, everything is written on one line, which is valid JSON but hard to look at. Open `student.json` in any text editor and you will see the structured layout with each key on its own indented line.

Python's `True` is written as `true` in the file, and `None` would be written as `null`. The `json` module handles these conversions automatically.

### json.dumps()

`json.dumps()` converts a dictionary into a JSON string instead of writing to a file. This is useful when you need to send data to an API, log it, or store it inside another structure.

```python
import json

student = {"name": "Alex", "age": 21}
json_string = json.dumps(student, indent=2)
print(json_string)
print(type(json_string))
```

**Output**

```text
{
  "name": "Alex",
  "age": 21
}
<class 'str'>
```

The result is a plain Python string — the dictionary has been serialised into JSON text.

## Nested JSON

JSON can hold objects inside objects — exactly like nested dictionaries in Python. This is how real data looks in practice.

```python
import json

order = {
    "order_id": "ORD-1042",
    "customer": {
        "name": "Maria",
        "email": "maria@example.com"
    },
    "items": [
        {"product": "Laptop", "qty": 1, "price": 999.99},
        {"product": "Mouse",  "qty": 2, "price": 19.99}
    ],
    "paid": True
}

with open("order.json", "w") as file:
    json.dump(order, file, indent=4)

with open("order.json", "r") as file:
    loaded = json.load(file)

print(loaded["customer"]["name"])
print(loaded["items"][0]["product"])
print(loaded["items"][1]["price"])
```

**Output**

```text
Maria
Laptop
19.99
```

Accessing nested values follows the same pattern as nested dictionaries — one key at a time, or one index at a time for lists.

## Quick Reference

| Function | Direction | Works with |
|---|---|---|
| `json.load(file)` | JSON file → Python dict | A file object from `open()` |
| `json.dump(dict, file)` | Python dict → JSON file | A file object from `open()` |
| `json.loads(string)` | JSON string → Python dict | A string |
| `json.dumps(dict)` | Python dict → JSON string | A string |

The pattern is easy to remember: no `s` = file, `s` = string.

## Common Mistakes

- Forgetting `import json` — the module is built in but still needs importing.
- Passing a string to `json.load()` — `load()` expects a file object; use `loads()` for strings.
- Forgetting `indent` — the file is valid but unreadable without it when you need to inspect it.
- Trying to use a Python `tuple` as a JSON value — JSON has no tuple type, so tuples are converted to arrays (lists) when written. Reading them back gives a list, not a tuple.
- Forgetting that JSON keys must be strings — a Python dictionary can use integers as keys, but `json.dump()` will either convert them to strings or raise an error.

## Practice

1. **Round-trip.** Create a dictionary with at least four fields describing a product (name, price, category, in_stock). Write it to `product.json` with `indent=4`, then read it back and print each field individually.

2. **List of objects.** Create a list of three dictionaries, each representing a student with name, age, and grade. Write the whole list to `students.json`, read it back, and print each student's name and grade.

3. **Nested JSON.** Write and read a JSON file representing a library book with fields: title, author, and a list of genres. Access and print each genre separately using a loop.

4. **Parse a string.** Given this string — `'{"city": "London", "temp_c": 18, "raining": false}'` — parse it with `json.loads()` and print each value with its Python type.
