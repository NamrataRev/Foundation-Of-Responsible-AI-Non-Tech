# Pandas

## The Problem This Solves

The folder traversal script in the previous file found `cs_results.csv` and identified it as a file for pandas to handle. Now the question is: what does pandas actually do with it?

The CS department's CSV looks like this:

```text
student_id,name,subject,marks,max_marks
S001,Alex,Mathematics,78,100
S002,Maria,Mathematics,92,100
S003,James,Mathematics,55,100
S004,Sam,Mathematics,,100
S005,Jordan,Mathematics,88,100
```

Five students, five columns, one missing value (Sam's marks are blank). A plain Python program could read this with the `csv` module and process it — but the moment you need to calculate averages, filter students who failed, find the highest scorer, or combine it with the management department's results, plain Python becomes difficult fast.

Pandas is a library built specifically for this kind of work. It reads the file in one line, handles missing values cleanly, and lets you filter, sort, group, and combine data with simple, readable expressions.

## What is a DataFrame?

The central object in pandas is a **DataFrame** — think of it as a Python spreadsheet. It has rows and columns. Each column has a name. Each row has an index. You can select a row, a column, a single cell, or any slice of the data with one line of code.

A **Series** is one column of a DataFrame — a single column with an index. When you pick one column from a DataFrame, you get a Series back.

```text
DataFrame (the whole table):

   student_id   name     subject   marks   max_marks
0       S001     Alex  Mathematics   78.0       100
1       S002    Maria  Mathematics   92.0       100
2       S003    James  Mathematics   55.0       100
3       S004      Sam  Mathematics    NaN       100
4       S005   Jordan  Mathematics   88.0       100

Series (one column):

0    78.0
1    92.0
2    55.0
3     NaN
4    88.0
Name: marks, dtype: float64
```

`NaN` stands for **Not a Number** — it is how pandas represents a missing value. It is not the string `"NaN"` or the number zero. It is a special marker that most pandas operations handle automatically.

## Reading a CSV File

One line reads the entire CSV into a DataFrame:

```python
import pandas as pd

df = pd.read_csv("results/cs_results.csv")
print(df)
```

**Output**

```text
  student_id    name      subject  marks  max_marks
0       S001    Alex  Mathematics   78.0        100
1       S002   Maria  Mathematics   92.0        100
2       S003   James  Mathematics   55.0        100
3       S004     Sam  Mathematics    NaN        100
4       S005  Jordan  Mathematics   88.0        100
```

The convention is to call the DataFrame `df`. The left-most column of numbers (0, 1, 2...) is the **index** — pandas adds it automatically. It is not a column in the file; it is a row label.

### Rows by Position — iloc

`iloc` selects by integer position, exactly like list indexing.

```python
print(df.iloc[0])      # first row as a Series
print(df.iloc[1:3])    # rows 1 and 2 as a DataFrame
print(df.iloc[-1])     # last row
```

**Output**

```text
student_id         S001
name               Alex
subject     Mathematics
marks              78.0
max_marks           100
Name: 0, dtype: object
```

### Rows by Label — loc

`loc` selects by index label. When the index is the default 0, 1, 2... it looks the same as `iloc`, but they are different — `loc` is label-based and `iloc` is position-based.

```python
print(df.loc[0])       # row with label 0
print(df.loc[0:2])     # rows with labels 0, 1, 2 — note: end is inclusive with loc
```

## Filtering Rows

A condition on a column returns a Series of `True`/`False` values. Passing that back into `df[...]` keeps only the `True` rows.

```python
passed = df[df["marks"] >= 60]
print(passed)
```

**Output**

```text
  student_id    name      subject  marks  max_marks
0       S001    Alex  Mathematics   78.0        100
1       S002   Maria  Mathematics   92.0        100
4       S005  Jordan  Mathematics   88.0        100
```

James scored 55 and Sam has no marks — both are excluded. The index labels (0, 1, 4) are preserved from the original.

Combine conditions with `&` (and) and `|` (or) — use parentheses around each condition:

```python
high_scorers = df[(df["marks"] >= 80) & (df["marks"].notna())]
print(high_scorers[["name", "marks"]])
```

**Output**

```text
     name  marks
1   Maria   92.0
4  Jordan   88.0
```

### Dropping Rows with Missing Values

```python
df_clean = df.dropna()
print(df_clean)
```

**Output**

```text
  student_id    name      subject  marks  max_marks
0       S001    Alex  Mathematics   78.0        100
1       S002   Maria  Mathematics   92.0        100
2       S003   James  Mathematics   55.0        100
4       S005  Jordan  Mathematics   88.0        100
```

Sam's row is gone. `dropna()` does not change `df` — it returns a new DataFrame. Assign it to keep the result.

### Filling Missing Values

Dropping a student entirely because one mark is missing may not be appropriate. Fill it with a default instead:

```python
df["marks"] = df["marks"].fillna(0)
print(df[["name", "marks"]])
```

**Output**

```text
     name  marks
0    Alex   78.0
1   Maria   92.0
2   James   55.0
3     Sam    0.0
4  Jordan   88.0
```

A common alternative is to fill with the column mean — absent students get the class average rather than zero:

```python
mean_marks = df["marks"].mean()
df["marks"] = df["marks"].fillna(mean_marks)
```

`value_counts()` counts how many times each unique value appears in a column — perfect for seeing how many students got each grade:


## Grouping and Aggregation

When the results file has multiple subjects, grouping calculates statistics per subject automatically.

```python
import pandas as pd

df = pd.read_csv("results/cs_results_multi.csv")
print(df.groupby("subject")["marks"].mean())
```

**Output**

```text
subject
Databases      74.5
Mathematics    78.25
Networks       81.0
Name: marks, dtype: float64
```

`groupby("subject")` splits the rows by subject. `["marks"]` selects the marks column. `.mean()` calculates the average within each group. Other aggregations work the same way: `.sum()`, `.max()`, `.min()`, `.count()`.

## Combining DataFrames

### pd.concat() — Stacking Rows

`pd.concat()` stacks DataFrames on top of each other — useful when all three departments have the same columns and you just want all rows together:

```python
import pandas as pd

cs_df   = pd.read_csv("results/cs_results.csv")
mgmt_df = pd.read_excel("results/management_results.xlsx")

combined = pd.concat([cs_df, mgmt_df], ignore_index=True)
print(combined.shape)
```

**Output**

```text
(10, 5)
```

`ignore_index=True` resets the row numbers so they run from 0 to 9 instead of having two sets of 0 to 4. Both DataFrames must have the same column names for this to work cleanly.

### df.merge() — Joining on a Common Key

`concat()` stacks rows. `merge()` joins two DataFrames side by side, matching rows that share a value in a common column — exactly like a JOIN in a database or a VLOOKUP in Excel.

The use case: the results file has student marks, and a separate attendance file has attendance percentages. Both have a `student_id` column. You want one combined DataFrame with marks and attendance together for each student.

```python
import pandas as pd

results = pd.DataFrame({
    "student_id": ["S001", "S002", "S003"],
    "name":       ["Alex", "Maria", "James"],
    "marks":      [78, 92, 55]
})

attendance = pd.DataFrame({
    "student_id":  ["S001", "S002", "S003"],
    "attendance":  [92, 85, 70]
})

combined = results.merge(attendance, on="student_id")
print(combined)
```

**Output**

```text
  student_id   name  marks  attendance
0       S001   Alex     78          92
1       S002  Maria     92          85
2       S003  James     55          70
```

`on="student_id"` tells pandas which column to match on. Rows with matching `student_id` values are joined together. The result has all columns from both DataFrames.

**What happens when a student appears in one file but not the other:**

By default, `merge()` keeps only rows that appear in both files — this is called an **inner join**. Use `how=` to change this:

| `how=` | Keeps |
|---|---|
| `"inner"` (default) | Only rows that match in both DataFrames |
| `"left"` | All rows from the left DataFrame, matched rows from the right |
| `"right"` | All rows from the right DataFrame, matched rows from the left |
| `"outer"` | All rows from both — unmatched rows get `NaN` in the missing columns |

```python
combined = results.merge(attendance, on="student_id", how="left")
```

Use `"left"` when the left DataFrame is the master list — you want all students from results, and attendance where available.

## Common Mistakes

- Forgetting `index=False` when saving — creates a spurious `Unnamed: 0` column on the next read.
- Using `=` to filter instead of `==` — `df[df["grade"] = "A"]` is a `SyntaxError`; use `==`.
- Not using parentheses around conditions when combining with `&` or `|` — `df[df["marks"] > 60 & df["grade"] == "A"]` raises an error; wrap each condition: `df[(df["marks"] > 60) & (df["grade"] == "A")]`.
- Forgetting that `dropna()` and `fillna()` return new DataFrames — the original is unchanged unless you reassign.
- Assuming `loc` and `iloc` behave the same — `df.loc[0:2]` includes row 2; `df.iloc[0:2]` does not.
- Treating `NaN` like zero or an empty string — `NaN != NaN` in Python; use `df.isnull()` to check for it.
- Using `concat()` when you need `merge()` — `concat()` stacks rows, `merge()` joins on a shared key. Using `concat()` on two DataFrames with different student sets produces duplicate rows and misaligned data.
- Forgetting `how="left"` with `merge()` when one DataFrame is the master list — the default inner join silently drops students who appear in only one file.
