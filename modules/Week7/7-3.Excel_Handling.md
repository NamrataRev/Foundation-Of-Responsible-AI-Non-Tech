# Excel Handling

## The Problem This Solves

The folder traversal script found `management_results.xlsx` and routed it to openpyxl. Pandas can read a plain Excel file in one line — but the management department's Excel file is not plain. It looks like this when you open it:

```text
Row 1: [MERGED CELL — "Management Department Results — Semester 2"]
Row 2: [empty]
Row 3: student_id | name | subject | marks | max_marks
Row 4: M001      | Emma | Finance | 81    | 100
Row 5: M002      | Noah | Finance | 67    | 100
...
```

There is a merged title cell at the top, an empty row, and then the actual data starting at row 3. `pd.read_excel()` would read the title as the first row of data and get confused. You need more precise control — reading a specific row range, skipping rows, writing back with formatting preserved.

This is what openpyxl is for. It gives you cell-level control over an Excel file — read exactly the cells you need, write exactly where you want, and apply formatting to produce reports a manager can open directly in Excel.

**Quick glossary:**

| Term | Meaning |
|---|---|
| **Workbook** | The whole Excel file — the `.xlsx` file itself |
| **Worksheet** | One tab/sheet inside the workbook |
| **Cell** | One box — addressed by column letter and row number, e.g. `A1`, `B3` |
| **Active sheet** | The sheet that is currently selected when you open the file |

## Installing and Importing

```text
pip install openpyxl
```

In Google Colab it is already available. Import it like this:

```python
import openpyxl
```

Pandas uses openpyxl internally when reading and writing `.xlsx` files — if you see `engine='openpyxl'` in pandas code, that is why.

## Reading an Excel File

### Opening a Workbook

```python
import openpyxl

wb = openpyxl.load_workbook("results/management_results.xlsx")
print(wb.sheetnames)
```

**Output**

```text
['Results', 'Summary']
```

`wb` is the workbook object. `sheetnames` lists every sheet tab in the file.

### Accessing a Sheet

```python
ws = wb["Results"]
print(ws.title)
print(ws.max_row)
print(ws.max_column)
```

**Output**

```text
Results
10
5
```

`max_row` and `max_column` tell you how far the data extends. These count populated cells — empty rows and columns at the end are not included.

To access the currently active sheet without knowing its name:

```python
ws = wb.active
```

### Reading One Cell

Two ways to address a cell — by letter-and-number or by row and column integers:

```python
print(ws["A3"].value)          # column A, row 3
print(ws.cell(row=3, column=1).value)   # same cell
```

**Output**

```text
student_id
```

Row 3 is the header row in the management file. Row 1 is the merged title, row 2 is empty.

### Reading All Data Rows

`iter_rows()` steps through a range of rows, giving you one tuple of cells per row. Use `min_row` to skip the title and empty rows:

```python
import openpyxl

wb = openpyxl.load_workbook("results/management_results.xlsx")
ws = wb["Results"]

for row in ws.iter_rows(min_row=3, values_only=True):
    print(row)
```

**Output**

```text
('student_id', 'name', 'subject', 'marks', 'max_marks')
('M001', 'Emma', 'Finance', 81, 100)
('M002', 'Noah', 'Finance', 67, 100)
('M003', 'Lily', 'Finance', 90, 100)
```

To read only specific columns — for example columns 1 to 3 — add `min_col` and `max_col`:

```python
for row in ws.iter_rows(min_row=3, min_col=1, max_col=3, values_only=True):
    print(row)
```

**Output**

```text
('student_id', 'name', 'subject')
('M001', 'Emma', 'Finance')
('M002', 'Noah', 'Finance')
('M003', 'Lily', 'Finance')
```

Column numbers start at 1 — column A is 1, B is 2, C is 3, and so on.

`values_only=True` gives you the cell's value directly instead of a cell object. Without it you would get `<Cell 'Results'.A3>` and have to call `.value` yourself.

### Converting to a pandas DataFrame

Once you have the rows, converting to a DataFrame is straightforward:

```python
import openpyxl
import pandas as pd

wb = openpyxl.load_workbook("results/management_results.xlsx")
ws = wb["Results"]

rows = ws.iter_rows(min_row=3, values_only=True)
data = list(rows)

header = data[0]
records = data[1:]

mgmt_df = pd.DataFrame(records, columns=header)
print(mgmt_df)
```

**Output**

```text
  student_id  name  subject  marks  max_marks
0       M001  Emma  Finance     81        100
1       M002  Noah  Finance     67        100
2       M003  Lily  Finance     90        100
```

The management DataFrame now has the same structure as the CS DataFrame from File 2. It is ready to be combined with `pd.concat()`.

### The Shortcut — pd.read_excel()

When the Excel file is straightforward — data starting at row 1, no merged cells, no formatting complications — pandas can read it directly:

```python
import pandas as pd

mgmt_df = pd.read_excel(
    "results/management_results.xlsx",
    sheet_name="Results",
    skiprows=2          # skip the title and empty row
)
print(mgmt_df)
```

**Output**

```text
  student_id  name  subject  marks  max_marks
0       M001  Emma  Finance     81        100
1       M002  Noah  Finance     67        100
2       M003  Lily  Finance     90        100
```

`skiprows=2` skips the first two rows before reading. Use `pd.read_excel()` when the file is clean and you just need the data. Use openpyxl when you need cell-level control — reading merged cells, specific ranges, or writing with formatting.

## Writing an Excel File

### Creating a New Workbook

```python
import openpyxl

wb = openpyxl.Workbook()
ws = wb.active
ws.title = "Graded Results"
```

A new workbook always starts with one sheet called `Sheet`. Rename it with `.title`.

### Writing to Cells

```python
ws["A1"] = "Student Results Report"
ws["A3"] = "student_id"
ws["B3"] = "name"
ws["C3"] = "marks"
ws["D3"] = "grade"
```

Or append a whole row at once — `append()` adds the values as the next available row:

```python
ws.append(["student_id", "name", "marks", "grade"])
ws.append(["M001", "Emma", 81, "A"])
ws.append(["M002", "Noah", 67, "C"])
ws.append(["M003", "Lily", 90, "A"])
```

### Writing from a pandas DataFrame

The most common pattern in the pipeline — process data in pandas, write the result to Excel with openpyxl for formatting:

```python
import openpyxl
import pandas as pd
from openpyxl.utils.dataframe import dataframe_to_rows

wb = openpyxl.Workbook()
ws = wb.active
ws.title = "Graded Results"

mgmt_df = pd.read_excel("results/management_results.xlsx",
                         sheet_name="Results", skiprows=2)

for row in dataframe_to_rows(mgmt_df, index=False, header=True):
    ws.append(row)

wb.save("results/processed/management_graded.xlsx")
print("Saved")
```

**Output**

```text
Saved
```

`dataframe_to_rows()` converts the DataFrame into a sequence of lists that `append()` can write one row at a time. `index=False` excludes pandas row numbers. `header=True` includes the column names as the first row.

### Saving

Always call `wb.save()` at the end — nothing is written to disk until you do:

```python
wb.save("results/processed/management_graded.xlsx")
```

## Adding Formatting

Formatting is the main reason to use openpyxl instead of just `pd.to_excel()`. A results report sent to a head of department should look professional — bold headers, coloured rows for failing students, column widths that do not cut off names.

### Merging Cells

`merge_cells()` combines a range of cells into one — exactly like "Merge and Center" in Excel. The value goes in the top-left cell of the range; the other cells become part of it and cannot hold separate values.

```python
ws.merge_cells("A1:E1")    # merge columns A through E on row 1
ws["A1"] = "Management Department — Graded Results"
ws["A1"].alignment = Alignment(horizontal="center")
```

To undo a merge later:

```python
ws.unmerge_cells("A1:E1")
```

Writing to any cell other than the top-left of a merged range raises an error — always write the value to the top-left cell first, then apply formatting.

### Bold and Font Size

```python
from openpyxl.styles import Font

ws["A1"] = "Student Results Report"
ws["A1"].font = Font(bold=True, size=14)

for cell in ws[3]:            # row 3 — the header row
    cell.font = Font(bold=True)
```

### Fill Colour — Highlighting Failing Students

```python
from openpyxl.styles import PatternFill

red_fill = PatternFill(fill_type="solid", fgColor="FFCCCC")

for row in ws.iter_rows(min_row=4):      # data rows start at row 4
    marks_cell = row[2]                   # column C — marks
    if marks_cell.value is not None and marks_cell.value < 40:
        for cell in row:
            cell.fill = red_fill
```

### Column Width

```python
ws.column_dimensions["A"].width = 12
ws.column_dimensions["B"].width = 20
ws.column_dimensions["C"].width = 10
ws.column_dimensions["D"].width = 10
```

### Alignment

```python
from openpyxl.styles import Alignment

ws["A1"].alignment = Alignment(horizontal="center")
```

### Putting Formatting Together

```python
import openpyxl
import pandas as pd
from openpyxl.styles import Font, PatternFill, Alignment
from openpyxl.utils.dataframe import dataframe_to_rows

mgmt_df = pd.read_excel("results/management_results.xlsx",
                         sheet_name="Results", skiprows=2)

mgmt_df["percentage"] = (mgmt_df["marks"] / mgmt_df["max_marks"]) * 100

wb = openpyxl.Workbook()
ws = wb.active
ws.title = "Graded Results"

ws["A1"] = "Management Department — Graded Results"
ws["A1"].font = Font(bold=True, size=14)
ws["A1"].alignment = Alignment(horizontal="center")
ws.merge_cells("A1:E1")

ws.append([])    # empty row 2

for row in dataframe_to_rows(mgmt_df, index=False, header=True):
    ws.append(row)

header_row = ws[3]
for cell in header_row:
    cell.font = Font(bold=True)

red_fill = PatternFill(fill_type="solid", fgColor="FFCCCC")
for row in ws.iter_rows(min_row=4):
    pct_cell = row[4]     # percentage column — index 4
    if pct_cell.value is not None and pct_cell.value < 40:
        for cell in row:
            cell.fill = red_fill

for col_letter, width in [("A", 12), ("B", 20), ("C", 12), ("D", 10), ("E", 14)]:
    ws.column_dimensions[col_letter].width = width

wb.save("results/processed/management_graded.xlsx")
print("Saved with formatting")
```

**Output**

```text
Saved with formatting
```

## Working with Multiple Sheets

```python
import openpyxl

wb = openpyxl.Workbook()

ws1 = wb.active
ws1.title = "CS Results"

ws2 = wb.create_sheet("Management Results")
ws3 = wb.create_sheet("Summary", 0)    # insert at position 0 — first tab

print(wb.sheetnames)
```

**Output**

```text
['Summary', 'CS Results', 'Management Results']
```

The pipeline writes the final consolidated report with one sheet per department plus a summary sheet — all in one `.xlsx` file.

## Where This Fits in the Pipeline

The folder traversal script routes `management_results.xlsx` to openpyxl. Openpyxl reads the data past the merged title cell, hands it to pandas as a DataFrame, and pandas processes it the same way it processed the CS CSV. At the end, the formatted results are written back to Excel.

```text
results/management_results.xlsx
        ↓
    openpyxl.load_workbook() — skips title, reads from row 3
        ↓
    dataframe_to_rows() → pandas DataFrame
        ↓
    percentage + grade calculated (same as CS results)
        ↓
    pd.concat() with CS DataFrame
        ↓
    openpyxl writes formatted final report
        ↓
    results/processed/management_graded.xlsx
```

The next file handles the third source — `external_board_results.pdf` — and extracts its table into another pandas DataFrame ready for the same `pd.concat()` step.

## Common Mistakes

- Forgetting `wb.save()` — the file on disk does not change until you save.
- Reading cell values without `values_only=True` — you get cell objects, not values.
- Using `ws["A1"]` on a sheet loaded with `data_only=False` — formula cells return the formula string, not the calculated value. Use `load_workbook(filename, data_only=True)` to get computed values instead of formulas.
- Confusing `min_row` in `iter_rows()` — row numbers in Excel start at 1, not 0.
- Writing to a cell that was part of a merged region — only the top-left cell of a merged group holds the value; writing to the others raises an error.
- Forgetting to import from `openpyxl.styles` — Font, PatternFill, and Alignment are in a submodule, not in openpyxl directly.
