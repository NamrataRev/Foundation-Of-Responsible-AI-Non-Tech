# PDF Extraction

## The Problem This Solves

The folder traversal script found `external_board_results.pdf` and routed it to pdfplumber. In the Python Automation Toolkit, pdfplumber handles the most difficult input format — PDFs that look perfectly readable to a human but are not plain text that Python can simply open and read. Every other tool in the toolkit reads a format that is already structured. A PDF requires an extra extraction step before the data can enter the pipeline.

The external exam board sends their results as a PDF — a format designed for printing and reading, not for data processing.

The PDF looks like this when you open it:

```text
Page 1:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  External Examination Board
  Semester 2 Results — Computer Science
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  student_id | name    | subject      | marks | max_marks
  -----------+---------+--------------+-------+----------
  E001       | Chris   | Data Science |  74   |   100
  E002       | Taylor  | Data Science |  88   |   100
  E003       | Morgan  | Data Science |  61   |   100
```

The table is right there — visible to your eyes. But Python cannot simply `open()` this file the way it opens a `.txt` or `.csv`. A PDF is a binary format. It does not store text the way a text file does. It stores instructions for drawing shapes and placing characters at specific coordinates on a page. To get the words out, you need a library that understands the PDF format and can reconstruct the text from those drawing instructions.

**Quick glossary:**

| Term | Meaning |
|---|---|
| **PDF** | Portable Document Format — binary format designed for printing, not data exchange |
| **Text extraction** | Reading the character positions from a PDF and reconstructing readable text |
| **Table extraction** | Detecting grid lines and whitespace in a PDF to reconstruct rows and columns |
| **Scanned PDF** | A PDF that is an image of a printed page — has no extractable text at all |
| **OCR** | Optical Character Recognition — software that reads text from images |

## Two Libraries — When to Use Which

| Library | Best for | Not ideal for |
|---|---|---|
| `pypdf` | Simple text extraction, page count, metadata, splitting/merging PDFs | Complex tables, PDFs with unusual layouts |
| `pdfplumber` | Tables, precise text positioning, complex layouts | Very large PDFs where speed matters |

Both work on the same PDF. `pdfplumber` is built on top of `pdfminer` and gives far better results on tables — which is what the external board's results file contains. This file covers both, starting with the simpler one.

## pypdf — Simple Text Extraction

### Opening a PDF and Reading Pages

```python
from pypdf import PdfReader

reader = PdfReader("results/external_board_results.pdf")

print(len(reader.pages))        # number of pages
print(reader.pages[0])          # page object
```

**Output**

```text
1
<pypdf._page.PageObject object at 0x...>
```

### Extracting Text from a Page

```python
from pypdf import PdfReader

reader = PdfReader("results/external_board_results.pdf")
page = reader.pages[0]
text = page.extract_text()
print(text)
```

**Output**

```text
External Examination Board
Semester 2 Results — Computer Science
student_id name subject marks max_marks
E001 Chris Data Science 74 100
E002 Taylor Data Science 88 100
E003 Morgan Data Science 61 100
```

The text is there — but all the table structure is gone. There are no columns, no separators, just words run together on each line. For simple text — paragraphs, headings, notes — this is fine. For a table you need to parse it further, or switch to pdfplumber.

### Looping Through All Pages

```python
from pypdf import PdfReader

reader = PdfReader("results/external_board_results.pdf")

for i, page in enumerate(reader.pages):
    print(f"--- Page {i + 1} ---")
    print(page.extract_text())
```

**Output**

```text
--- Page 1 ---
External Examination Board
Semester 2 Results — Computer Science
student_id name subject marks max_marks
...
```

### Reading PDF Metadata

```python
from pypdf import PdfReader

reader = PdfReader("results/external_board_results.pdf")
meta = reader.metadata

print(meta.title)
print(meta.author)
print(meta.creation_date)
```

**Output**

```text
Semester 2 Results
External Board Office
2026-05-15 09:30:00
```

Metadata is optional — not all PDFs have it. If a field is missing, `None` is returned.

## pdfplumber — Table Extraction

### Opening a PDF

```python
import pdfplumber

with pdfplumber.open("results/external_board_results.pdf") as pdf:
    print(len(pdf.pages))
    print(type(pdf.pages[0]))
```

**Output**

```text
1
<class 'pdfplumber.page.Page'>
```

Always use `pdfplumber.open()` inside a `with` block — it ensures the file is properly closed when you are done, the same way `open()` works for text files.

### Extracting Text with pdfplumber

```python
import pdfplumber

with pdfplumber.open("results/external_board_results.pdf") as pdf:
    page = pdf.pages[0]
    text = page.extract_text()
    print(text)
```

**Output**

```text
External Examination Board
Semester 2 Results — Computer Science
student_id name subject marks max_marks
E001 Chris Data Science 74 100
E002 Taylor Data Science 88 100
E003 Morgan Data Science 61 100
```

The text output is similar to pypdf. The difference appears when you call `extract_table()`.

### Extracting a Table — extract_table()

`extract_table()` detects the grid structure of the table and returns a list of lists — each inner list is one row, each element in that list is one cell value.

```python
import pdfplumber

with pdfplumber.open("results/external_board_results.pdf") as pdf:
    page = pdf.pages[0]
    table = page.extract_table()
    for row in table:
        print(row)
```

**Output**

```text
['student_id', 'name', 'subject', 'marks', 'max_marks']
['E001', 'Chris', 'Data Science', '74', '100']
['E002', 'Taylor', 'Data Science', '88', '100']
['E003', 'Morgan', 'Data Science', '61', '100']
```

Every value is a string — including the numbers. The table structure is preserved: the first row is the header, subsequent rows are data. This is exactly what you need to build a pandas DataFrame.

### Converting to a pandas DataFrame

```python
import pdfplumber
import pandas as pd

with pdfplumber.open("results/external_board_results.pdf") as pdf:
    page = pdf.pages[0]
    table = page.extract_table()

header  = table[0]
records = table[1:]

ext_df = pd.DataFrame(records, columns=header)

ext_df["marks"]     = pd.to_numeric(ext_df["marks"])
ext_df["max_marks"] = pd.to_numeric(ext_df["max_marks"])

print(ext_df)
print(ext_df.dtypes)
```

**Output**

```text
  student_id    name       subject  marks  max_marks
0       E001   Chris  Data Science     74        100
1       E002  Taylor  Data Science     88        100
2       E003  Morgan  Data Science     61        100

student_id     object
name           object
subject        object
marks           int64
max_marks       int64
dtype: object
```

`pd.to_numeric()` converts a column of strings to numbers. Without this step, `marks` would still be a string — and `"74" + "88"` is `"7488"`, not `162`.

### Multiple Tables on One Page

Some pages have more than one table. `extract_tables()` (plural) returns a list of all tables found:

```python
import pdfplumber

with pdfplumber.open("results/external_board_results.pdf") as pdf:
    page = pdf.pages[0]
    tables = page.extract_tables()
    print(f"Found {len(tables)} table(s) on this page")
    for i, table in enumerate(tables):
        print(f"\nTable {i + 1}:")
        for row in table:
            print(row)
```

**Output**

```text
Found 2 table(s) on this page

Table 1:
['student_id', 'name', 'subject', 'marks', 'max_marks']
['E001', 'Chris', 'Data Science', '74', '100']
...

Table 2:
['Statistic', 'Value']
['Average', '74.3']
['Pass Rate', '100%']
```

### PDFs Spread Across Multiple Pages

When the results run over more than one page, loop through all pages and collect the tables:

```python
import pdfplumber
import pandas as pd

all_rows = []
header   = None

with pdfplumber.open("results/external_board_results_multi.pdf") as pdf:
    for page in pdf.pages:
        table = page.extract_table()
        if table:
            if header is None:
                header = table[0]      # take header from first page only
            all_rows.extend(table[1:]) # skip header on subsequent pages

ext_df = pd.DataFrame(all_rows, columns=header)
print(ext_df.shape)
```

**Output**

```text
(15, 5)
```

The `if header is None` check ensures the column names are taken only from the first page. Pages 2, 3, and beyond repeat the header inside the PDF — `table[1:]` skips it on each subsequent page.

## The Limitations Every Fresher Must Know

### Scanned PDFs Return Empty Text

A scanned PDF is a photograph of a printed page. It looks exactly like a normal PDF on screen — but it contains no text, only an image. `extract_text()` and `extract_table()` both return `None` or empty strings.

```python
import pdfplumber

with pdfplumber.open("results/scanned_results.pdf") as pdf:
    text = pdf.pages[0].extract_text()
    print(repr(text))    # repr() shows exactly what is there
```

**Output**

```text
''
```

An empty string means the PDF is scanned. The fix is **OCR** — Optical Character Recognition software reads the image and converts it to text. The most common Python option is `pytesseract`, but OCR is a separate topic and outside the scope of this pipeline.

How to tell if a PDF is scanned before running your script:

```python
import pdfplumber

with pdfplumber.open("results/mystery.pdf") as pdf:
    text = pdf.pages[0].extract_text()
    if text and text.strip():
        print("Text-based PDF — extraction will work")
    else:
        print("Scanned PDF — OCR required")
```

### Text Order May Not Match Visual Order

PDF stores text by position on the page, not in reading order. A two-column PDF may return the text of both columns merged together in an unexpected sequence. `pdfplumber` handles single-column layouts and simple tables well. Complex multi-column layouts may need additional post-processing.

### Password-Protected PDFs

```python
from pypdf import PdfReader

reader = PdfReader("results/protected.pdf")

if reader.is_encrypted:
    reader.decrypt("password123")

text = reader.pages[0].extract_text()
print(text)
```

If you do not have the password, the PDF cannot be decrypted and extraction is not possible.

## Common Mistakes

- Forgetting `with` when using pdfplumber — the file stays open and may cause issues on Windows where open files are locked.
- Not converting numeric columns with `pd.to_numeric()` — string numbers look correct but break all arithmetic.
- Calling `extract_table()` on a scanned PDF and assuming `None` means no table exists — it may mean the PDF is scanned. Always check `extract_text()` first.
- Using `extract_table()` (singular) on a page with multiple tables — only the first table is returned. Use `extract_tables()` (plural) to get all of them.
- Taking the header from every page in a multi-page loop — the header row repeats on each page; skip it with `table[1:]` on all pages after the first.
- Assuming text extraction order matches visual reading order — always inspect the raw output before writing post-processing logic that depends on order.
